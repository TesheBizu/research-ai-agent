# ResearchAI Documentation

This directory contains technical specifications, architecture blueprints, research notes, and setup guides for the ResearchAI platform.

## Documentation Structure

- **Architecture**: System architecture diagrams, component boundaries, and data flow specifications.
- **API Reference**: Specification for backend REST endpoints and streaming protocols.
- **Cala.ai Integration**: Protocols, MCP tool definitions, and knowledge retrieval schemas.
- **LLM Prompting & Reasoning**: Agent prompt templates, reasoning chains, and evaluation criteria.
